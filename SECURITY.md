# Security policy

Use [GitHub private vulnerability reporting](https://github.com/AbhishekSinghDev/phonivra/security/advisories/new) to report a suspected vulnerability. Include the Phonivra version or commit, operating system, affected feature, and enough detail for a maintainer to investigate.

Use synthetic input when possible. Keep access tokens, voice recordings, private scripts, and complete user-data directories out of reports. For ordinary bugs, follow the [contribution guide](CONTRIBUTING.md).

Security fixes target the default branch and the latest stable desktop release when one is available. GitHub Release notes describe fixes and how to update.
