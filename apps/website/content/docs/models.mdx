## Compare models

| Model             | Languages           | When to use it                                                              |
| ----------------- | ------------------- | --------------------------------------------------------------------------- |
| Chatterbox Turbo  | English             | Use for English narration with reaction tags such as `[laugh]`.             |
| Multilingual V3   | 23 languages        | The default for all 23 languages. Supports cross-language voice references. |
| AI4Bharat IndicF5 | 11 Indian languages | Use with a short reference recording and its exact transcript.              |

### Automatic selection

**Auto** selects Multilingual V3 for its 23 languages and IndicF5 for the additional Indian languages. You can select either model for Hindi. Choose Turbo for English scripts that use reaction tags.

If you use automatic language detection, check the language before generating from a short script or one that mixes languages.

### Supported languages

Multilingual V3 supports Arabic, Chinese, Danish, Dutch, English, Finnish, French, German, Greek, Hebrew, Hindi, Italian, Japanese, Korean, Malay, Norwegian, Polish, Portuguese, Russian, Spanish, Swahili, Swedish, and Turkish. The app does not add Hebrew vowel marks or Russian stress marks.

IndicF5 supports Assamese, Bengali, Gujarati, Hindi, Kannada, Malayalam, Marathi, Odia, Punjabi, Tamil, and Telugu.

## Download a model

Open **Models** and download the model you want. Phonivra downloads the files from Hugging Face, checks them, and keeps them in its model cache. You can pause and resume a download. Once the model is ready, it can generate speech offline.

For IndicF5, accept the conditions on the [IndicF5 model page](https://huggingface.co/ai4bharat/IndicF5), create a Hugging Face read token, and connect it in **Settings → Storage and downloads**. Save a voice preset with 5–12 seconds of speech and the exact transcript before generating.

## Choose where generation runs

In **Settings → General**, use **Auto** to let Phonivra choose NVIDIA CUDA or Apple Metal when available and CPU otherwise. You can also choose a device explicitly. If a graphics device fails to load a model, try CPU. Phonivra keeps one model loaded at a time.
