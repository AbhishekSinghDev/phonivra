## Check for an installer

Check [GitHub Releases](https://github.com/AbhishekSinghDev/phonivra/releases) for a Debian package (`.deb`) for Linux x64. Follow its release notes and download the speech model during first-run setup. On Windows and macOS, use the source setup below.

Release notes list the supported OS versions, download size, and required disk space. Compare the SHA-256 of your download with its entry in `SHA256SUMS.txt`. The Linux x64 installer uses CPU inference.

On Linux, open a terminal in the download folder and run `sudo apt install ./Phonivra-<version>-linux-x64.deb`, substituting the file name you downloaded. APT installs the required system libraries along with Phonivra.

To update manually, close Phonivra and install the newer build for the same platform. Back up important projects and custom recordings before an upgrade, and check the release notes for any version-specific steps.

Find the installed version under **Settings → Diagnostics**.

## Run from source

Use this option if an installer is unavailable or you want to work with the source code. Run the commands in a desktop session that can open graphical apps.

Before you start, install:

- Git
- Node.js 24.22.0 or a later version of Node 24, plus pnpm 12.15.0
- Python 3.11 through 3.13 and uv. Python 3.12 is recommended.
- FFmpeg and FFprobe, both available on your PATH

```bash
git clone https://github.com/AbhishekSinghDev/phonivra.git
cd phonivra
pnpm install --frozen-lockfile
pnpm engine:setup
pnpm dev:desktop
```

Engine setup installs Python dependencies in the checkout. Linux x64 uses CPU-only PyTorch by default. The desktop app starts the engine when it opens.

## Finish setup in the app

1. Check that **Local engine** and **Audio tools** show **Ready**, then select **Continue**.
2. Choose a language supported by Multilingual V3 and select **Continue**. You can add IndicF5 after setup.
3. Select **Download model** and wait for verification, then select **Continue**.
4. Select **Generate test clip**. When it finishes, select **Open studio**.

You need an internet connection to download models. A verified model can be used offline afterward. Continue with [your first narration](/docs/first-narration).
