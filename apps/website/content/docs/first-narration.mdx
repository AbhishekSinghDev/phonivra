---
title: Make your first narration
description: Generate a short clip with the default voice, listen to it, and save it.
---

## Add a short script

After [setup](/docs/install), open **Text to speech**. Type or paste a few sentences into the editor. For a first test, use a line you can recognize easily.

> The room went quiet. Then someone knocked.

## Choose a voice and language

Select the language of the script and leave the model set to **Auto**. Multilingual V3 can use the default voice. If Auto selects IndicF5, choose a saved voice preset with a reference transcript. If Phonivra asks for the model, download it before generating.

Keep the format set to **WAV** for the first test. You can choose another [audio format](/docs/audio) before generating your next take.

## Generate and listen

Choose **Generate narration** and wait for the result. Play the finished audio in the result panel. If a line sounds rushed, add a pause or adjust the speed and generate another take.

Phonivra saves finished takes in the audio library. Choose **Save audio** to put a copy in a folder of your choice. Open the result details for subtitles, the transcript, and other export options.
